# UI Docs & Design System

*(See [ui-context.md](file:///e:/Coding/Projects/gemini-watermark-remover/docs/ui-context.md) for the complete design tokens and component specifications.)*

## Key Highlights

- **Framework**: Tailwind CSS + shadcn/ui.
- **Theme**: Dark Technical Workspace (Obsidian / Zinc / Slate with Indigo / Emerald telemetry accents).
- **Typography**: Sans for UI labels (`Geist Sans` / `Inter`), Monospace with `tabular-nums` for coordinates, FPS, and confidence (`Geist Mono`).
- **Core Widgets**:
  - Interactive Before/After Split-Slider
  - Video Frame Scrubber with timecode & frame counter
  - Drag-and-drop / Clipboard paste zone
  - Batch Queue Drawer with ZIP export
